# 🧋 50嵐 智慧團購點餐系統 (Smart Boba Order System)

> 專為公司與辦公室打造的現代化 50嵐手搖飲團購點餐系統。具備多品項購物車、客製化規格調整、主揪一鍵電話點餐稿、CSV 匯出核對與雙向 Google 試算表連線！

---

## ✨ 核心特色與升級功能

1. **全新現代時尚輕奢視覺**
   - 汲取 50嵐經典識別色，注入現代精品手搖飲風格（墨翡綠、晨曦金、雪白玻璃擬態）。
   - 完美響應式設計（RWD）：電腦端雙欄吸頂購物面板、手機端底部抽屜（Bottom Drawer），點餐超滑順。

2. **完整 22 款人氣手搖飲菜單**
   - **找好茶（原茶系列）**：四季春青茶、茉莉綠茶、阿薩姆紅茶、黃金烏龍
   - **找奶茶（經典奶茶）**：波霸奶茶、珍珠奶茶、50嵐奶茶、混珠奶茶、椰果奶茶、四季春奶茶
   - **找拿鐵（純鮮奶拿鐵）**：紅茶拿鐵、波霸紅茶拿鐵、綠茶拿鐵、烏龍拿鐵
   - **鎮店之寶（招牌口感）**：1號（四季春+珍波椰）、波霸鮮奶、燕麥紅茶拿鐵
   - **鮮果特調**：冰淇淋紅茶、檸檬青茶、梅果綠茶、金桔檸檬、多多綠茶

3. **強大多品項購物車**
   - 支援一次加入多杯飲料，每杯皆可單獨調整甜度、冰塊、加料與專屬備註。
   - 支援加料複選（波霸、珍珠、椰果、混珠、燕麥、布丁、冰淇淋），即時計算累加金額。
   - 購物單內隨時增減杯數或刪除。

4. **團購主神隊友功能（Host Dashboard）**
   - **即時指標**：自動計算今日總杯數、總金額、參與訂購同仁數。
   - **一鍵複製門市電話點單稿**：系統自動彙整相同飲料與規格（如：`波霸奶茶 大杯/微冰微糖 x 3`），打電話或傳 LINE 給門市一秒搞定！
   - **一鍵匯出 CSV / Excel**：完整時間、部門、姓名、品項與單價明細。
   - **收款狀態勾選**：一鍵標記同仁「已收款 / 未收款」，主揪對帳超輕鬆。

5. **全環境雙模相容**
   - **GitHub Pages 靜態部署**：可直接在任何瀏覽器開啟，所有資料儲存於瀏覽器 LocalStorage。
   - **Google Apps Script 雲端串接**：支援部署為 GAS Web App，自動寫入 Google 試算表，並支援 Email 與 LINE 官方通報！
